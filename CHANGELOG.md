# Changelog

## [1.0.0] - 2026-08-14
### Added
- Org profile page (`profile/README.md`).
- Org-wide default community health files: `CONTRIBUTING.md`,
  `CODE_OF_CONDUCT.md`, `SECURITY.md`, `SUPPORT.md`.
- Default `.github/ISSUE_TEMPLATE/` (bug report, feature request,
  config) and `.github/PULL_REQUEST_TEMPLATE.md` for any repository
  added to the org without its own.
- `scripts/check-files.mjs` + CI verifying required org-level files
  are present.
