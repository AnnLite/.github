# Support

## For users of the platform

If you're using Ann Lite and need help (a donation issue, a content
question, an accessibility problem), use the Contact form on
`ann-lite-web`, once deployed. Until then, open an issue on the
relevant repository.

## For developers/contributors

- Start with `ann-lite-docs` — it's the cross-project source of truth
  for architecture, setup, and policy.
- Each repository's `README.md` has exact local setup commands
  (`LOCAL_DEVELOPMENT.md` in `ann-lite-docs` has the recommended
  cross-repo order).
- Open a GitHub issue on the specific repository for bugs or feature
  requests — use the provided issue templates.
- For security issues, see `SECURITY.md` — never a public issue.

## Response time

This is currently a small-team project — please be patient with
response times on issues and pull requests.
