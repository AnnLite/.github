# Code of Conduct

## Our standard

Ann Lite is built to serve people with respect and compassion. That
standard applies to how we build it, too.

- Treat every contributor, maintainer, and user with respect,
  regardless of denomination, background, nationality, or technical
  experience level.
- No harassment, discrimination, or personal attacks in issues, pull
  requests, code review, or any project space.
- Assume good faith; disagree about code and ideas, not people.
- Protect the dignity and privacy of the vulnerable people this
  project ultimately serves — see `ann-lite-docs/docs/CHILD_SAFETY.md`
  for specific rules that follow from this.

## Scope

This applies across every repository in the `ann-lite` organization.

## Reporting

Report unacceptable behavior privately via the contact method in
`SECURITY.md`, or GitHub's built-in reporting tools. Reports are
handled confidentially.

## Enforcement

Maintainers may edit, remove, or reject contributions that don't
follow this Code of Conduct, and may temporarily or permanently ban
contributors for repeated or severe violations.

Adapted in spirit from the [Contributor Covenant](https://www.contributor-covenant.org/).
